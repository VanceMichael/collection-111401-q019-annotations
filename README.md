# 重排文档页面的批注锚点采集

当前浏览器入口查看资料基本信息及首屏正文和批注，保留来源文档身份，不进行摘要或解释。批注采集驱动真实阅览器建立文本选区，记录作者、线程状态与可回指原文的文本锚点，并区分已定位、多个候选与原文不匹配。

## 运行

使用 Node.js 22。依赖版本已锁定，运行、测试和演示不下载任何数据或软件。浏览器运行环境预装 Playwright 1.56.1 与 Chromium 1194；本机安装使用 `npm ci`，只在环境准备阶段执行。

- `npm test`：执行本地来源交互、收件存储与浏览器批注锚点测试。
- `npm run build`：逐个检查模块语法。
- `npm run demo`：启动本地来源，运行当前领取流程与版本切换采集，打印真实收件结果后退出。
- `npm start`：在 127.0.0.1:8080 启动本地来源，PORT 可调整。`GET /health` 返回服务与当前来源版本；原有 `/_health` 仍可使用。

容器方式：`docker build -t collection-annotations .`，然后 `docker run --rm --network none collection-annotations`。镜像构建属于环境准备，运行时不访问公网。

## 项目结构

`src/domain.mjs` 提供当前业务读取入口（含版本切换采集）；`src/annotations.mjs` 在真实浏览器中收齐分页、逐条建立批注文本锚点；`src/client.mjs` 负责人工指定地址的有限大小原始领取；`src/archive.mjs` 保存内容、来源凭据与批注采集记录（`collections/`）；`src/browser.mjs` 启动浏览器。`provider/` 是独立的本地来源服务，`docs/source-contract.md` 说明它的资料和状态约定，包括锚点状态、分页未加载与已删除线程的区分。演示使用临时目录，正式接入可向业务入口传入持久目录。

本地服务中的机构、记录和文件都是合成业务资料，不使用真实账号、个人信息或第三方站点数据。当前演示通常十秒内结束，全部本地测试应在六十秒内结束。
